## About Me

I work across the full robotics stack — CAD and embedded prototyping, physics simulation, perception, estimation, and closed-loop control validated on real hardware.

- **Core focus** — real-time state estimation (EKF/UKF Kalman filtering), autonomous navigation (KISS-ICP SLAM, point cloud processing), and ROS 2 manipulation pipelines.
- **Full-loop engineering** — comfortable moving between CAD, embedded firmware on STM32/ESP32, simulation in Gazebo Harmonic and Isaac Sim, and validation on physical hardware.
- **What I've shipped** — an edge vision system that cut production-line failures by 80%, ROS 2 obstacle-avoidance nodes running at roughly 25 ms latency, and a hybrid Kalman filter holding 0.098 m RMSE on position estimates.

Graduated in May 2026 with an M.S. in Mechatronics, Automation, and Robotics from the University of Delaware. Looking for full-time Robotics Software Engineer, Controls Engineer, or Autonomy/Perception roles — OPT-eligible.

### Franka Panda Voice-Controlled Pick-and-Place
**[`franka-cv-voice-pipeline`](https://github.com/PaONEkaruchola/franka-cv-voice-pipeline)**

<img src="https://img.shields.io/badge/ROS_2-0B7285?style=flat-square&logo=ros&logoColor=white"/> <img src="https://img.shields.io/badge/C%2B%2B-D9480F?style=flat-square&logo=cplusplus&logoColor=white"/> <img src="https://img.shields.io/badge/MoveIt_2-0B7285?style=flat-square"/> <img src="https://img.shields.io/badge/OpenCV-2B8A3E?style=flat-square&logo=opencv&logoColor=white"/> <img src="https://img.shields.io/badge/Gazebo_Harmonic-495057?style=flat-square"/>

- Markerless 2D-to-3D vision — no fiducials or printed markers in the workspace

- Physics simulation synced to a shared `/clock`, keeping vision, planning, and control on the same timeline
